# Data: GW150914 in the two LIGO detectors

Strain recorded by LIGO Hanford (H1) and LIGO Livingston (L1) around
GW150914, the first gravitational wave detected (14 September 2015,
09:50:45 UTC), as released by the Gravitational Wave Open Science Center.

| file | detector | start (GPS) | length | rate |
|---|---|---|---|---|
| H-H1_LOSC_4_V2-1126259446-32.hdf5 | Hanford, Washington | 1126259446 | 32 s | 4,096 Hz |
| L-L1_LOSC_4_V2-1126259446-32.hdf5 | Livingston, Louisiana | 1126259446 | 32 s | 4,096 Hz |

The event is at GPS 1126259462.4, 16.4 s into each file. Strain is in
`strain/Strain` (float64), with the sample spacing in its `Xspacing`
attribute. Unchanged from GWOSC:
https://gwosc.org/s/events/GW150914/H-H1_LOSC_4_V2-1126259446-32.hdf5 and
the same with `L-L1`.
