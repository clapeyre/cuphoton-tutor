Set up the tutor

{{brand}}'s tutor is a language model that reads the lessons, runs code on this machine and talks with you. Tell the course which model to use. It tests the model with one small call before saving.

Which model? The course was written and tested with Claude Sonnet 5.5. The model must support tool calls, and it does better if it reads images (it looks at the figures it makes). Smaller models tend to lose track of the lesson's questions. A model served on this machine shares the GPU the lessons use.
